# Bookwise prototype

ต้นแบบเว็บอ่านหนังสือภาษาไทยอยู่ใน `Readwise-glass.html` และเปิดผ่าน `index.html` ได้เมื่อเผยแพร่เป็นเว็บไซต์แบบ static

## เปิดในเครื่อง

เปิด `index.html` หรือ `Readwise-glass.html` ในเบราว์เซอร์ ข้อมูลความคืบหน้า ไฮไลต์ โน้ต บุ๊กมาร์ก และการ์ดทบทวนเก็บใน `localStorage` ของเบราว์เซอร์นั้น

## เนื้อหา

`CHAPTER_CONTENT_PROMPTS.md` เป็นชุดพรอมป์ต์สำหรับวางแผน เขียน และตรวจเนื้อหารายบท เนื้อหาหนังสือที่แสดงในเว็บขณะนี้เป็นข้อมูลจำลอง

## ขั้นต่อไป

1. เชื่อม repository นี้กับบริการเผยแพร่ static site เพื่อให้มี URL ที่เปิดได้ทุกที่
2. เพิ่มบัญชีผู้ใช้และฐานข้อมูล แล้วนำข้อมูลจาก `localStorage` ไปเก็บและซิงก์ต่อผู้ใช้
3. แยก HTML, CSS, JavaScript และข้อมูลหนังสือออกจากไฟล์เดียวเมื่อเริ่มเพิ่มเนื้อหาจริง
